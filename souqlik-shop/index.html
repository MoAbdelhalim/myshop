About this admin panel

This panel and the storefront both read and write the same database — so anything you save here (catalogue, settings) goes live for every visitor immediately, and every order a customer places, from their own phone, shows up in Orders here. Product photos go through a separate photo storage service; uploading one here stores it there and saves the link into the catalogue.
